# Bookmark v1.1.2

- 搜索默认覆盖全部分类，支持多关键词、切换当前分类和键盘导航。
- 新增“置顶常用”，通过卡片星标添加或取消，支持鼠标拖拽或选中后按 Alt+←/→ 排序并保存顺序；没有置顶时隐藏该区域。
- 导入前自动备份已有书签，支持选择版本恢复；恢复前再次保存当前书签。内容未变时不重复备份，保留最近 20 份。
- 新增一键专注模式，退出后恢复原有主题与动效设置。
- 适配九种布局，优化中等窗口宽度下的搜索栏和手机显示。

## 安装包

- 本次提供 macOS 安装包和校验文件，不附 Windows EXE；Windows 已安装用户可通过在线升级获取程序更新。
- macOS Apple Silicon：`Bookmark_v1.1.2_macos_arm64.dmg`，附 SHA-256 校验文件。
- 将“书签”拖到“应用程序”并替换旧版，重新打开后页面版本应为 v1.1.2。
- 使用 ad-hoc 签名，未经 Apple Developer 公证，首次打开可能出现系统安全提示。
