# Bookmark v1.1.1

## 界面与手机布局

- 优化九种布局在手机上的导航、卡片宽度和间距，修复分组看板横向溢出；紧凑布局默认双列，长标题支持双行显示。
- 目录树在手机上可展开、收起，选择分类后保留可操作的键盘焦点；分类标题和标签不再重复显示完整路径。
- 分类总览展示网站图标，居中起始页对齐更统一，浅色主题的替代字母图标更清晰。
- 天气背景跟随主题配色，水墨主题保留原有画面，太阳位置和右上角按钮对比度得到改善。
- 外观面板标题与提示文字改为单行排列；未手动选择动态效果时遵循系统“减少动态效果”设置。

## 书签同步与后台

- macOS 在外观面板关闭按钮旁提供重启图标，同步帮助中也可重启。两处均先弹出确认框，确认后重启后台并自动刷新，保留当前分类和外观设置。
- 同步失败时显示简短原因和可展开的解决步骤，可直接打开 macOS 权限设置。
- 浏览器读取优先使用最近使用的账号配置和账号书签；导入时正确识别不同语言的书签栏，避免多出一层分类。
- 安装版与源码版按目录识别各自后台，避免误用其他目录的服务。
- 多页面共用天气缓存和更新检查结果，后台页面暂停定时天气请求；静态资源更新后可重新校验，减少旧页面残留。
- 本地写入操作校验请求来源；网址中的账号密码不会显示或发给图标服务，脚本书签保持可见但不能在主页执行。

## 下载与升级

- Windows 用户可通过现有在线升级获取本版本的程序更新；本次发行不附 Windows EXE。
- macOS Apple Silicon：`Bookmark_v1.1.1_macos_arm64.dmg`，附 SHA-256 校验文件。
- 安装包仅包含公开示例，私人书签保留在本机。覆盖安装前请关闭旧后台；新版 macOS 可使用页面中的重启入口。
- macOS 安装包使用 ad-hoc 签名。覆盖安装后若权限开关已打开但仍无法同步，请在“完全磁盘访问权限”中移除旧 Bookmark 条目，重新添加 `/Applications/Bookmark.app` 并启用，再重启书签。旧版页面没有重启入口时，先在活动监视器退出 Bookmark 后台，再打开新版应用。
