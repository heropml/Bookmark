# Bookmark v1.1.4

- 新增分类区块排序：支持拖动、方向按钮与 Alt+方向键，顺序按当前分类保存在本机，可恢复默认顺序；横向排列使用左右操作，纵向排列使用上下操作，窗口宽度变化时自动适配。
- 分类整理入口放在“我的书签”数量旁，默认淡化，鼠标悬停或键盘聚焦时清晰显示；纵向分类的把手与上下按钮放在分类标题旁，移动整组分类时保留组内书签顺序。
- 分组看板与分类瀑布流支持小、中、大列宽；搜索期间暂停整理，详细表格不提供分类排序入口。
- 新增外观方案，可保存、应用、更新和删除主题、图标、布局、密度、动效参数及专注状态；自动主题与跟随系统的动态效果保留原有行为。
- 新增书签右键及更多菜单，支持在新标签页打开、复制网址与查看完整名称、网址和分类；可通过 Shift+F10 操作，复制受限时显示可手动复制的网址。

## 安装包

- Windows 10/11 x64：下载 `Bookmark_Setup_v1.1.4.exe`，附 SHA-256 校验文件。
- 安装包只包含公开示例书签；覆盖安装保留本机私人书签，安装后页面版本应为 v1.1.4。
- 普通用户无需安装 Python 或 Git，也可使用页面内的在线升级。分类顺序和外观方案只保存在当前浏览器中。
- 本次未构建 macOS DMG，macOS 安装版继续使用 v1.1.2。
- Windows 安装包未进行代码签名，可能显示未知发布者提示。
