## 页面布局

- 新增顶部标签、居中起始页和分类折叠三种布局，布局选项扩展为九宫格。
- 居中起始页对齐时钟与顶部操作，并保留背景大时钟。

## 书签密度

- “外观 → 页面布局”中提供 60%–120% 的书签密度调节，设置保存在本机。
- 最小密度使用居中图标格；紧凑布局同步消除图标旁的空白。

## 安装与升级说明

- Windows 10/11 x64 安装包名称：`Bookmark_Setup_v1.0.9.exe`，安装后通过桌面/开始菜单启动。
- macOS（Apple Silicon）安装包名称：`Bookmark_v1.0.9_macos_arm64.dmg`，打开后将“书签”拖入“应用程序”启动。
- 发行包不包含私人书签，仅含公开示例书签与运行时；升级仅覆盖应用程序文件，不清理本地书签和偏好设置。
