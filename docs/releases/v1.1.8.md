置顶与外观配置现在由本地服务保存到本机文件，减少清理浏览器数据、切换端口后设置丢失的问题。

- 新增“配置备份”：支持配置导出、导入和历史恢复，保留最近 20 份快照；连续修改每 5 分钟最多保留一份，导入或恢复会在替换前备份。
- 多个页面修改不同设置会自动合并；同一项设置发生冲突时明确提示，避免旧页面覆盖新配置。
- 保存失败时保留可导出的未保存副本；同步或恢复书签后，等待配置保存完成再刷新。
- 首次打开新版时迁移当前浏览器已有配置；无效旧值不再阻止其他有效设置迁移，原值保留供导出。
- 自动定位城市和当前分类保留在浏览器中，避免页面启动或分类切换产生不必要的配置写入。
- 普通静态服务器继续使用浏览器存储，并明确提示其保存范围。

## 安装与升级

- Windows 10/11 x64：下载 `Bookmark_Setup_v1.1.8.exe`，附 SHA-256 校验文件。安装包未进行代码签名，可能显示未知发布者提示。
- macOS Apple Silicon：下载 `Bookmark_v1.1.8_macos_arm64.dmg`，附 SHA-256 校验文件。应用使用 ad-hoc 签名；若被系统拦截，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。
- 安装包仅包含公开示例书签，不包含私人书签、配置或备份。首次使用可同步浏览器书签或导入 HTML。
- Windows 可从页面在线升级；使用 EXE 覆盖安装前请先停止旧版后台服务。macOS 请退出旧版 Bookmark，将 DMG 中的应用拖入「应用程序」替换。
- 升级后，请先用原来保存设置的浏览器和地址打开一次主页，完成首次迁移。已在升级前被清除且没有备份的置顶与外观，无法通过本次升级找回。
