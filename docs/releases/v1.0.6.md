# Bookmark v1.0.6

- 图标动效新增翻转、震颤、聚焦、滑行、扭转、闪现、漂移、心跳。
- 鼠标拖尾新增火花、丝带、音符、像素、冰晶、墨迹、心愿、云烟。
- 背景特效新增极光、泡泡、烟火、数字雨、星云、波纹、光束、彩纸。
- 修复动态效果已开启但受浏览器“减少动态效果”设置影响而不显示的问题，页面开关现在统一控制全部动画。
- 文件夹计数保持透明背景，同时恢复浅色与国风主题的文字层次，并改善浅色布局预览对比度。
- 整理拖尾和天空粒子配置，未知拖尾类型不再静默降级。

## 下载与使用

Windows 10/11 x64 下载 `Bookmark_Setup_v1.0.6.exe`。安装包未签名，Windows 可能提示未知发布者；可使用同名 `.sha256` 文件核对完整性。

安装包仅含公开示例书签。打开主页，点击“同步书签”，选择 Chrome / Edge 并确认；也可从开始菜单导入书签 HTML。macOS 使用源码与系统 Python，支持 Chrome / Safari 同步。

私人书签只保存在本机，不包含在发行附件内。覆盖安装和在线升级会保留私人数据与外观设置。
