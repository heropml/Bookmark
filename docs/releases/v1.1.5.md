# Bookmark v1.1.5

- 将“外观方案”入口统一为外观实验室的卡片样式，包含图标、副标题、右侧箭头及一致的间距和圆角。
- 为外观方案图标补上悬停动画，遵循动态效果开关。
- 外观方案管理改为复用菜单左侧的设置面板，悬停、点击、返回、关闭和 Escape 操作与其他外观设置一致。
- 保留方案保存、应用、更新和删除，以及自动主题、系统动态效果偏好和专注状态的原有行为。

## 安装包

- Windows 10/11 x64：下载 `Bookmark_Setup_v1.1.5.exe`，附 SHA-256 校验文件。安装包未进行代码签名，可能显示未知发布者提示。
- macOS Apple Silicon：下载 `Bookmark_v1.1.5_macos_arm64.dmg`，附 SHA-256 校验文件；打开后将“书签”拖入“应用程序”替换旧版。安装包使用 ad-hoc 签名，未经 Apple 公证。
- 安装包仅包含公开示例书签。Windows 覆盖安装保留本机私人书签；macOS 私人书签保存在 `~/Library/Application Support/Bookmark`。首次使用可同步浏览器书签或导入导出的 HTML 文件。
- 安装后页面版本应显示 v1.1.5。Windows 已安装用户建议通过页面内的在线升级更新；使用 EXE 覆盖安装前请先停止旧版后台服务，以免运行文件被占用。macOS 安装版通过新版 DMG 覆盖安装升级。
