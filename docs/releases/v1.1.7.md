## 安装与升级

- Windows 10/11 x64：下载 `Bookmark_Setup_v1.1.7.exe`，附 SHA-256 校验文件。安装包未进行代码签名，可能显示未知发布者提示。
- macOS Apple Silicon：下载 `Bookmark_v1.1.7_macos_arm64.dmg`，附 SHA-256 校验文件。应用使用 ad-hoc 签名；若被系统拦截，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。
- 安装包仅包含公开示例书签。首次使用可同步浏览器书签或导入 HTML。
- Windows 可从页面在线升级；使用 EXE 覆盖安装前请先停止旧版后台服务。macOS 请退出旧版 Bookmark，将 DMG 中的应用拖入「应用程序」替换。
