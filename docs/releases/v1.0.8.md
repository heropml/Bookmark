## 视觉与图标

- 16 套网站图标风格扩展：在原有 8 套基础上新增以下 8 套：
  - `outline`
  - `halo`
  - `frame`
  - `badge`
  - `ink`
  - `grain`
  - `mirror`
  - `circuit`
- 外观设置页同步展示并支持全部图标风格。
- 切换即时生效；新旧图标风格可互相对照预览。
- 继续保持主题、布局、天气和同步行为。
- 升级后保留原有私人书签与外观设置。

## 安装与升级说明

- Windows 10/11 x64 安装包名称：`Bookmark_Setup_v1.0.8.exe`，安装后通过桌面/开始菜单启动。
- macOS（Apple Silicon）安装包名称：`Bookmark_v1.0.8_macos_arm64.dmg`，打开后将“书签”拖入“应用程序”启动。
- 发行包不包含私人书签，仅含公开示例书签与运行时；升级仅覆盖应用程序文件，不清理本地书签和偏好设置。
