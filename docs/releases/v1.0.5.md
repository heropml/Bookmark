# Bookmark v1.0.5

- 新增 Windows 安装向导，内置 Python，无需预装 Git；支持覆盖安装与卸载。
- 安装版和 ZIP 版支持免 Git 双源在线升级、文件校验、备份和实时进度。
- 主页新增“同步书签”：识别当前浏览器，可选择来源，确认后才更新主页；不修改浏览器收藏夹。
- 安装版与 Git 源码版后台按目录隔离，同目录重复打开复用服务。
- 覆盖安装、卸载只处理本安装目录的后台，保留私人书签及更新备份。
- 统一安装包运行时文件字节，避免 Windows 换行符差异导致在线升级被误阻止。
- 右上角入口顺序调整为“同步书签 → 数量 → 外观”。

## 下载与使用

Windows 10/11 x64 下载 `Bookmark_Setup_v1.0.5.exe`。安装包未签名，Windows 可能提示未知发布者；可使用同名 `.sha256` 文件核对完整性。

安装包仅含公开示例书签。打开主页，点击“同步书签”，选择 Chrome / Edge 并确认；也可从开始菜单导入书签 HTML。macOS 使用源码与系统 Python，支持 Chrome / Safari 同步。

私人书签只保存在本机，不包含在发行附件内。不要将安装目录选为 Git 工程目录。
