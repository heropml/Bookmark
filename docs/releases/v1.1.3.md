# Bookmark v1.1.3

- 页面布局扩展至 16 种，新增分类瀑布流、横向书架、分类索引、详细表格、大小磁贴、左右分屏和极简文字；桌面选择面板统一为 4×4。
- 磁贴按密度设置同步调整尺寸，置顶与普通书签保持等宽等高，只通过星标区分。
- 修复浅色主题开启专注模式后卡片与分类栏背景变暗的问题。
- 加深外观选项原有的选中边框，保持原来的颜色和样式。
- Windows 外观菜单恢复右上角“重启书签”入口，确认后重启当前后台并自动刷新页面，保留书签、分类和外观设置。

## 安装包

- Windows 10/11 x64：下载 `Bookmark_Setup_v1.1.3.exe`，附 SHA-256 校验文件。
- 安装包只包含公开示例书签；覆盖安装保留本机私人书签，安装后页面版本应为 v1.1.3。
- 普通用户无需安装 Python 或 Git，也可使用页面内的在线升级。
- 本次未构建 macOS DMG，macOS 安装版继续使用 v1.1.2。
- Windows 安装包未进行代码签名，可能显示未知发布者提示。
