## 浏览器书签同步

- Windows 同步窗口会自动检索有可读取书签的 Chrome、Edge、Brave、Vivaldi、Opera、Opera GX、QQ、360 极速/极速 X、搜狗高速、夸克和 UC 浏览器。
- 检测到的浏览器会显示为可选来源；同步只读取所选来源，不会修改浏览器收藏夹。
- 新增“其他浏览器”入口：选择后从系统文件窗口导入浏览器导出的标准 HTML 书签文件，适用于 Firefox、360 安全浏览器及其他未直接识别的浏览器。
- 每次同步仍只选择一个来源，并替换本主页的书签与分类，避免不同浏览器的重复书签混合。

## 安装说明

- Windows 10/11 x64 安装包：`Bookmark_Setup_v1.1.0.exe`。
- 安装包不包含私人书签，仅含公开示例书签；同步或导入的书签仅保存在本机。
