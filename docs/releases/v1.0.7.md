# Bookmark v1.0.7

## 分类顺序与名称显示

- 从 Chrome、Edge 或 Safari 同步后，根分类、子分类、目录树和分类卡片均保持浏览器中的原始顺序。
- 分类名称以当前列中最长名称对齐，最多预留四个汉字宽度；超过四个字的名称默认省略。
- 鼠标悬停或键盘聚焦超长名称时，名称会在原位置水平滚动，便于完整查看。

## 皮肤协调的提示卡

- 超长分类名称提供完整名称提示卡，不再使用与界面割裂的白色提示。
- 极光、赛博、余烬、深渊、星云、棱镜、曜石、宣纸、雪、樱、青瓷、水墨、黛青、朱砂和夜墨均有各自协调的渐变、描边和阴影色。

## macOS 安装包

- 新增 Apple Silicon（M 系列）macOS 安装包 `Bookmark_v1.0.7_macos_arm64.dmg`：打开后把“书签”拖入“应用程序”即可，不需要另装 Python 或保留源码目录。
- 主页在 macOS 当前设置的默认浏览器中打开；个人书签与外观设置保存在 `~/Library/Application Support/Bookmark`，升级不会覆盖。
- 首次同步 Chrome 或 Safari 书签前，需在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”中添加并启用 `/Applications/Bookmark.app`，然后完全退出并重新打开应用。未授权时页面会给出对应的指引提示。
- 安装版发现新版本时只在左下角提示并可打开发行版页面，不会就地改写已安装的应用；升级请下载新版 DMG 覆盖“应用程序”中的旧版本。

## 安装说明

- 支持 Windows 10 / 11 x64 与 Apple Silicon macOS；Windows 安装包未进行代码签名，macOS 安装包使用本地 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中确认。
- 安装包只包含公开示例书签。首次使用可在开始菜单同步 Chrome/Edge 书签、在 macOS 同步 Chrome/Safari 书签，或导入书签 HTML；私人数据始终保留在本机。
